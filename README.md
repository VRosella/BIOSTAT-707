Place the PhysioNet set A record files in `data/set-a/` and the outcomes file at `data/Outcomes-a.txt`, then run `pixi run --locked checkpoint1` from the repository root. The command executes `checkpoint1.ipynb` in a fresh kernel and writes the report to `output/checkpoint1.html`, along with `set-a_long.csv` (original and cleaned measurements with timestamps and quality flags), `set-a_wide.csv` (one row per stay with admission descriptors and measurement summaries), `static.csv`, descriptive tables, missingness summaries, and PNG figures. The notebook reads local data without downloading or modifying them. Commit the notebook, environment files, and rendered HTML; raw data and other generated outputs are ignored. If an existing user-level `python3` kernel selects another environment, run `JUPYTER_PREFER_ENV_PATH=1 pixi run --locked checkpoint1` locally so Jupyter uses Pixi’s kernel.
